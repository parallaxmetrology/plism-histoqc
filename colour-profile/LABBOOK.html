Paired HistoQC with embedded ICC profiles applied

Same 26 PLISM scans, same HistoQC revision, configuration, seed and 156 fields as the original paired study. One change: every region HistoQC reads is first converted from the scan's embedded colour profile to sRGB. Prompted by the HistoQC owner's suggestion on choosehappy/HistoQC#343.

1. Record

  • Plan written and frozen before any run in this folder: PLAN.md, SHA-256 d94a853793d8884a66e2e96929339a0ca7556b8ccc3d7d8ab337ceb93fd44aa3, 2026-11-24T21:58:20Z.
  • Prior look, disclosed in the plan: thumbnail tissue brightness with and without profiles (section 5).
  • Environment rebuilt to the original record: Python 3.10.22, numpy 1.23.5, scipy 1.10.0, scikit-learn 1.2.1, scikit-image 0.19.3, Pillow 9.4.0, openslide-python 1.4.6, OpenSlide 4.0.1. HistoQC f35e518, default config.ini, seed 20261111, one process.
  • Conversion: OpenSlide.read_region wrapped at run time (HistoQC source untouched); Pillow ImageCms (LittleCMS), perceptual intent, RGB converted and alpha kept. HistoQC's packaged training and template images are not converted.
  • Result posted as a reply on choosehappy/HistoQC#343, 24 November 2026.

2. Gate

With the conversion switched off, the rebuilt environment reproduced all 26 of 26 original final mask PNGs byte for byte (SHA-256 against the original final_hashes.csv), and the original result: 52 switched, 47 AT2-only, 5 GT450-only. Pass. In the converted run, all 26 scans carried a profile ("AT2" on every AT2 file, "Segue_v2" on every GT450 file), and every scan read the same pyramid levels and produced the same mask size as without conversion.

5. Prior thumbnail look

Before the plan: median tissue luma (0 to 255) on 2000-pixel thumbnails, tissue taken as luma below the 95th percentile minus 25 on the unconverted thumbnail, and the same pixels measured after conversion (table above). Median AT2 to GT450 gap across sections: 40.5 without profiles, 6.9 with. With the profiles, AT2 renders slightly brighter than GT450 on 13 of 13 sections.

6. Scope

Same array, scanners, pipeline and settings; only the colour conversion changes. One rendering intent was run. Descriptive: it shows that applying the vendor profiles changes which fields the default pipeline admits here, and how far the two scanners then agree. It does not say which mask is right. Most of the 156 fields, which were chosen as tissue locations, are excluded on both scans under the default configuration with or without profiles; no step trace was run for the converted masks, so which steps drive the remaining exclusions and switches is not measured here.
